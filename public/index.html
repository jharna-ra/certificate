Online verification (QR opens your verification website)
When this is filled in and you are signed in, the QR code holds only a short link such as https://verify.iceskills.in/c/AB12CD34EF. Anyone who scans it sees every detail of that certificate on your verification site. Only the details are saved in your Supabase database (no files), so storage stays tiny.










QR code data pattern (used only when online verification is Off)
Tokens like {Name} are filled from each candidate. Warning: the QR code contains the candidate’s personal information in plain text. It is not an online verification system.
