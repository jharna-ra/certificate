4Generate
Word: one editable .docx per candidate in a ZIP. PDF: downloads a ZIP containing the same generated Word certificates plus a one-click PDF converter. On Windows, double-click Convert-to-PDF.bat after extracting the ZIP. It uses Microsoft Word PDF export when installed (best layout match); otherwise it tries LibreOffice. The converted PDF files are saved in a PDF folder. This conversion step runs on your computer, not inside the browser. QR codes contain candidate personal data.








Upload a Word template
Templates are uploaded to the shared ICES cloud library and become visible to all users. Older versions are retained.




Shared & saved templates
Cloud templates are shared across users. Locally saved templates remain visible only in this browser. Cloud templates can be downloaded but not renamed or deleted from this page.


Generation history
Records only. Generated files are never stored. Kept until you delete them, except oldest-first cleanup at 85% storage.


Audit log


QR code data pattern
Tokens like {Name} are filled from each candidate. Warning: the QR code contains the candidate’s personal information in plain text. It is not an online verification system.




QR position on certificate
Adjust if the QR touches text. Smaller QR codes are harder to scan, so use the compact pattern if you shrink it.


Settings


Browser storage
Data stays on this browser. Clearing browser data or switching computers removes it, so keep backups. Free hosting limits can change, and no uptime is promised.
